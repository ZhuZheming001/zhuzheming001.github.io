# 私密空间操作教程（Zheming 专用）

> 覆盖两个核心操作：**审核添加新账号**、**添加/修改/删除私密文章**。
> 全程在项目文件夹 `/Users/zhuzheming/zhuzheming001.github.io` 下操作。

---

## 一、审核添加新账号

### 背景

申请人在 `https://zhuzheming001.github.io/apply/` 填表 → 得到一段**加密密文** → 发给你。
你解密看到申请信息，通过后账号才能登录私密空间。

### 操作步骤（收到密文后）

**第 1 步：查看申请内容**

打开终端，执行：

```bash
cd ~/zhuzheming001.github.io
python3 scripts/audit_apply.py "申请人发来的那串密文"
```

> 密文太长不好复制时，直接运行 `python3 scripts/audit_apply.py`（不带参数），
> 出现 `粘贴申请密文:` 后把密文粘进去回车即可。

屏幕会显示：

```
📋 收到的申请：
  账号: xxx
  密码: xxx
  姓名: xxx
  电话: xxx
  时间: xxx
审核通过？[y/N]
```

**第 2 步：决定通过或拒绝**

- ✅ 通过：输入 `y` 回车 → 显示 `✅ 账号 xxx 已加入 accounts.json`
- ❌ 拒绝：直接回车（默认就是 N）→ 什么都不写入

**第 3 步：重新加密（⚠️ 这步不能省！）**

```bash
python3 scripts/encrypt_private.py
```

按提示输入：
- `设置账号 [默认 news]:` → 直接回车（用默认）或输入你的账号
- `设置密码:` → 输入你的私密空间密码（输入时不显示字符，这是正常的）

> 这里只是**操作者身份确认**，不是改密码。缺了这步，新账号的文章密文里没有他的密钥，登录不了。

**第 4 步：推送**

- 用 GitHub Desktop：Commit（填说明，如 `approve xxx`）→ Push
- 或命令行：`git add -A && git commit -m "approve xxx" && git push`

**第 5 步：告诉申请人**

> "审核通过了，去 https://zhuzheming001.github.io/private/ 用你申请的账号登录吧"

### 注意事项

- 第 3 步**不能跳过**，跳过 = 新账号白审核
- 申请信息里密码是**明文显示**的，审核时注意屏幕别被别人看到
- 拒绝申请只需直接回车，没有额外操作

## 二、添加 / 修改 / 删除私密文章

### 写一篇新私密文章

**第 1 步：新建文件**

在项目 `_private/` 文件夹里新建 `.md` 文件（文件名随意，建议英文），例如 `_private/MyNote.md`：

```markdown
---
title: 我的随笔
date: 2026-09-28 12:00:00 +0800
---

这里写正文，Markdown 语法和公开文章完全一样，表格、代码块、图片都支持。
```

**第 2 步：加密**

```bash
python3 scripts/encrypt_private.py
```

输入操作账号（回车默认 news）+ 密码，看到 `✅ 已加密 N 篇文章` 即成功。

**第 3 步：推送**（GitHub Desktop Commit + Push）

**第 4 步：验证**

访问 `https://zhuzheming001.github.io/private/` 登录后应能看到新文章（记得硬刷新 `Cmd+Shift+R`）。

### 修改 / 删除

| 操作 | 做法 |
|---|---|
| 修改 | 编辑 `_private/` 里对应文件 → 重跑加密 → 推送 |
| 删除 | 删掉 `_private/` 里对应文件 → 重跑加密 → 推送（线上自动消失） |

## 三、其他管理操作

### 删除账号 / 改密码

编辑根目录 `accounts.json`（本地文件，不推送）：

```json
[
  { "user": "news", "pass": "你的密码", "name": "Zheming", "phone": "", "added": "2026-09-19" },
  { "user": "别人账号", "pass": "他的密码", "name": "名字", "phone": "手机号", "added": "2026-09-28" }
]
```

- 删账号：删掉对应那一行
- 改密码：改对应 `pass` 的值

然后：**重跑加密 → 推送**，改动生效。

### 忘记自己密码

编辑 `accounts.json` 把 `news` 的 `pass` 改成新密码 → 重跑加密 → 推送。
（其他人的账号不受影响）

## 四、文件位置速查

| 文件 / 目录 | 作用 | 是否推送 |
|---|---|---|
| `_private/*.md` | 私密文章源文件 | ❌ 永不推送（.gitignore 保护） |
| `accounts.json` | 账号库 | ❌ 本地 |
| `scripts/keys/` | RSA 密钥对 | ❌ 本地 |
| `scripts/audit_apply.py` | 审核申请（第 1、2 步） | ✅ |
| `scripts/encrypt_private.py` | 加密全部私密文章（第 3 步） | ✅ |
| `private.md` / `private-*.md` | 加密后的列表页和文章页 | ✅ 推送到线上 |

```
收到密文 → audit 解密 → y 通过 → encrypt 重新加密 → push → 通知申请人
新文章   → 放进 _private → encrypt 重新加密 → push → 完成
```
